# KG-LLM-Nepali-Biomedical-QA

Code and data for the paper "A Comparative Study of Knowledge Graph-Integrated LLMs for Hallucination Reduction in Low-Resource Biomedical Question Answering".

## Contents
- `questions_english.tsv`: 50 English benchmark questions with ground-truth answers
- `questions_nepali.tsv`: 50 Nepali benchmark questions with ground-truth answers
- `src/`: pipeline code (to be added)

## Data
The benchmark questions are built over a two-hop PrimeKG subgraph centered on multiple sclerosis. PrimeKG is described in Chandak et al., Scientific Data 10, 67 (2023).
